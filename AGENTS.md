# Magic Timer — AGENTS.md

## Что это

Одностраничное PWA-приложение — таймер для фокусников. Работает полностью на клиенте (vanilla JS, CSS, HTML). Серверной части нет.

**Ключевая фишка:** подмена миллисекунд. Вместо реальных сотых долей секунды таймер показывает заранее заданные «магические» числа (циклически перебирает список значений). Это позволяет фокуснику «предсказывать» время на табло.

## Ключевые архитектурные решения

### Без фреймворков
- **Никаких React/Vue/Angular**, никаких сборщиков (Vite, Webpack).
- Чистый JS + CSS + HTML. Открыть `index.html` — и готово.
- Если потребуется добавить сборку — пересмотреть весь подход, это будет нарушение текущей архитектуры.

### PWA (Progressive Web App)
- `manifest.json` с `"display": "standalone"`, портретная ориентация.
- Service Worker (`sw.js`) кэширует статику для офлайн-работы.
- Все названия (`name`, `short_name`, `title`) — пустая строка или пробел (`" "`). **Никакого видимого брендирования на экране.**
- `theme-color` и `background_color` — `#000000`.
- При добавлении новых файлов — обновить `STATIC_ASSETS` в `sw.js` и увеличить версию кэша (строка `CACHE = 'magic-timer-vN'`).

### Дизайн — Samsung Clock
- Чёрный фон (`#000000`), серые поверхности (`#1c1c1e`, `#2c2c2e`).
- Моноширинный шрифт (SF Mono → Fira Code → JetBrains Mono → Consolas).
- Формат времени: `MM : SS , CC` — двоеточия между минутами/секундами, **запятая** перед сотыми.
- Все цифры белые (`color: var(--text)`) одинаковой толщины (`font-weight: 200`).
- Сотые — мельче (0.65em).
- Кнопки в стиле Samsung: зелёная пилюля (Старт), красная пилюля (Стоп), серые круги (Сброс, Зафиксировать).

### Логика таймера
- `performance.now()` для отсчёта (не `setInterval`, не `Date.now()`).
- `requestAnimationFrame` для обновления дисплея — плавное обновление каждые ~16ms.
- При остановке/фиксации таймер подменяет сотые на значение из списка `fakeMs`.
- Список `fakeMs` циклически перебирается: `state.checkpointIndex % list.length`.
- Значения по умолчанию: `[40, 3, 21]`.
- При `visibilitychange` корректирует `startTime`, чтобы таймер не ушёл вперёд.

### Режимы (табы внизу)
1. **Секундомер** — замеры записываются в список, показывается подменённое время.
2. **Чекпоинты** — запись фиксирует время и номер чекпоинта, можно переключать отображение (подменённое/реальное/оба).

### Настройки (модальное окно по ⋮)
- **Подмена миллисекунд**: список чисел 0-99, добавляются/удаляются по одной, есть пресеты (Классика [40,3,21,...], Ровные [0], Макс [99]).
- **Режим отображения чекпоинтов**: `faked` (только подменённые), `real` (реальные), `both` (оба).
- **Сбросить все настройки** — возвращает к дефолтам.
- Настройки сохраняются в `localStorage` под ключом `magicTimer_settings`.

### Клавиатурные сокращения
| Клавиша | Действие |
|---------|----------|
| `Space` | Старт / Стоп |
| `F` | Зафиксировать (записать чекпоинт/замер) |
| `R` | Сброс (когда таймер остановлен) |
| `Escape` | Закрыть настройки |

### i18n
- Интерфейс на русском языке: «Старт», «Стоп», «Продолжить», «Сброс», «Чекпоинты», «Секундомер», «Замеры», «Настройки» и т.д.
- Не переводить на английский без явного запроса.

### Service Worker
- Версия кэша: `magic-timer-v3` (увеличивать при изменении статики).
- Кэширует: `/`, `/index.html`, `/css/style.css`, `/js/app.js`, `/manifest.json`, `/icons/icon.svg`.
- Стратегия: cache-first → fetch fallback.

## Нюансы и подводные камни

### При редактировании
- **Не добавлять фреймворки и сборщики.** Проект умышленно без них.
- **Не менять формат времени.** `MM : SS , CC` с запятой и пробелами — это осознанный дизайн фокусника.
- **Не добавлять логотипы, названия, брендинг.** Даже иконка PWA — просто бесцветный SVG. Название приложения в манифесте и title — пустая строка.
- **Не менять цветовую схему.** Чёрный фон, белые цифры, серые элементы — это Samsung-стиль.
- **При добавлении новых файлов** не забыть: (1) добавить в `STATIC_ASSETS` в `sw.js`, (2) увеличить версию кэша.

### Потенциальные улучшения (если попросят)
- Звуковой сигнал при фиксации чекпоинта.
- Вибрация на мобильных устройствах при старте/стопе/фиксации.
- Экспорт/импорт настроек.
- Возможность задать не только подмену миллисекунд, но и подмену секунд/минут.
- Тёмная тема (уже есть) → светлая тема как опция.

### JavaScript особенности
- В `app.js` используется простой `$ = id => document.getElementById(id)` для быстрого доступа к DOM.
- Состояние приложения — один объект `state`.
- События навешиваются через `addEventListener`, не через `onclick` в HTML.
- Проверка `<input>` и `<select>` в обработчике клавиатуры: если фокус на поле ввода — клавиши Space/R/F не срабатывают.

### Тестирование
- Открыть `index.html` в браузере.
- Проверить оба режима.
- Проверить подмену миллисекунд: остановить таймер — должны появиться подставные значения.
- Проверить клавиатурные сокращения.
- Проверить PWA: Chrome DevTools → Application → Manifest + Service Worker.
- Проверить сохранение настроек (закрыть/открыть страницу).

## Перенос на сервер/Orange Pi

Проект работает локально — просто открытием файла. Если нужно хостить:
- Разместить папку на статике (nginx, Caddy).
- Никаких Node.js, PM2, билдов не требуется.
